Get a temporary client key

Run this in Terminal with OPENAI_API_KEY already set. Copy the returned key, then connect before it expires. 

curl -sS -X POST https://api.openai.com/v1/realtime/client_secrets \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"session":{"type":"realtime","model":"gpt-realtime"}}' \
  | jq -r '.value // .error'

Use only the temporary key here. For a deployed app, create temporary keys on your server. Serve this file over localhost or HTTPS for microphone access.
